Turn speech into text with **Lanson Live API**. Get an API key, choose the way your app handles audio, and follow the matching quickstart.

## 1. Get an API key

Create an API key in the [Developer Console](https://live.lansonai.com/?panel=developer). Copy and save it when it appears; the key is shown only once. Keep it on your server and send it as an `Authorization: Bearer` header.

[**Create an API key →**](https://live.lansonai.com/?panel=developer)

## 2. Choose your audio workflow

### Realtime

Stream live microphone audio over WebSocket and receive completed transcripts as people speak.

[Open the Realtime Quickstart →](/docs/realtime/quickstart)

### Segment

Send a short speech clip in one HTTP request when your application has already detected the speech boundaries. The example returns the transcript in the response.

[Run the Segment request →](/docs/api-reference/segment-transcription)

### Batch

Submit a recording by URL, then retrieve the transcript when processing finishes.

[Transcribe a recording →](/docs/recorded/transcribe-audio)

## 3. Confirm your first result

You have a successful transcription when you can read recognized words from the result: the Realtime event's `text`, the Segment response's `text`, or the Batch result's `output.result.segments[].text` after the job is `complete`.
