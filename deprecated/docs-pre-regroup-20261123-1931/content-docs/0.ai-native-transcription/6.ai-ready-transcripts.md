updated: 2026-11-22
---

A live transcript often becomes input to an AI agent, search system, workflow, or user interface. These applications need to know more than the recognized words.

Lanson Live includes structured events and fields such as utterance order, transcript state, and downstream-readiness indicators. They help applications process speech in sequence and decide how to handle a result.

These indicators describe delivery state and processing signals; they are not a guarantee that every recognized word is correct.
