**Lanson Live API** uses prepaid credits. Usage is priced per audio minute and charged by actual processed audio seconds, without rounding each request up to a full minute. These API rates are separate from Lanson Live App subscriptions.

::callout{icon="i-lucide-info" color="primary"}
New API developer accounts include **$5 of free credit**. Create a key and check your balance in the [Developer panel](https://live.lansonai.com/?panel=developer).
::

::api-pricing
::

Refinement and translation are optional features. Realtime refinement is off by default; Batch review is on by default where correction is available. See [LiveFinal™](/docs/concepts/livefinal) for correction and delivery behavior.

## Credits, balance, and top-ups

- Usage is deducted from your prepaid USD balance. The **Developer** panel shows your current balance, usage, and free credit.
- You can top up with a card from the same panel. Credits are added automatically after Stripe confirms payment.
- The free credit is a one-time signup grant; it is not a monthly allowance.
- When your balance is exhausted, top up before sending more audio.
