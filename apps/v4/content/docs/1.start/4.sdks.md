# SDKs

There is **no official LansonAI SDK yet**. The API is designed to be used directly over HTTPS and WebSocket, which keeps you free of an SDK versioning dependency.

## Direct usage

- **Realtime** — connect a WebSocket to the endpoint in [Realtime API](/docs/api-reference/realtime-api) and exchange JSON messages ([Client Messages](/docs/api-reference/client-messages), [Server Events](/docs/api-reference/server-events)).
- **Recorded** — call the HTTP endpoints in [Segment Transcription](/docs/api-reference/segment-transcription) and [Batch Jobs](/docs/api-reference/batch-jobs).

## Language notes

- **Browser / Node / Bun** — use the built-in `WebSocket` and `fetch`, or a thin wrapper.
- **Python** — use `websockets` / `aiohttp` for realtime and `httpx` / `requests` for recorded.
- **Server-side** — keep the API key on the server and issue short-lived session tokens to browsers ([Authentication](/docs/start/authentication)).

## When an SDK would help

If you need a typed client or framework integration, start from the runnable examples in the [Guides](/docs/guides) section.
