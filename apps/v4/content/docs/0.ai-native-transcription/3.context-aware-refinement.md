Every utterance is reviewed inside the live pipeline by a dedicated reasoning model—not just the ASR decoder's built-in language head. Treating acoustic recognition as one input signal alongside conversation context, the reasoning layer resolves phonetic lookalikes, recovers proper nouns, and keeps terminology consistent.

This is not a second API that developers must wire up after transcription. It runs automatically before utterance delivery.

Reasoning review does not mean rewriting every sentence. When the recognized words already match the speaker, leaving them untouched is the right outcome.

::

## What is targeted disambiguation

The reasoning layer resolves ambiguity—phonetic lookalikes (`"land sun"` → `"Lanson"`), domain terms, and proper nouns—using global session context. Sentence structure and speaker phrasing are preserved verbatim when recognition is already accurate.
