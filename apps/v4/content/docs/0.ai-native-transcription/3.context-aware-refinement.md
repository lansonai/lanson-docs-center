Every completed utterance in Lanson Live can pass through an in-pipeline AI review stage before crossing the delivery boundary.

> **AI Review is not the ASR model's built-in language understanding.**
>
> Lanson Live uses a separate language reasoning model to review each transcription candidate against the conversation's context. This happens inside the real-time transcription pipeline, before the completed text is delivered.
>
> The speech recognition model identifies the words. The reasoning model evaluates them. StableStream™ makes it possible to deliver the reviewed result as the first committed transcript.

## ASR built-in language modeling vs. dedicated LLM reasoning

When conventional speech-to-text providers talk about "language understanding," they are referring to **the ASR model's internal language modeling**—the statistical decoder that predicts likely word sequences from acoustic features, hotword biases, and a few preceding tokens.

Lanson Live operates on a fundamentally higher level by pairing **ASR candidate recognition** with a **separate language reasoning model (LLM)** inside the real-time pipeline:

| Capability Dimension | Layer 1: ASR Built-In Language Modeling | Layer 2: Lanson Live Dedicated Reasoning Model |
|---|---|---|
| **Primary input** | Acoustic frames and local phoneme probabilities | Candidate transcript + phonetic clues + multi-turn conversation history |
| **Context horizon** | Extremely narrow, sound-bound local window (seconds) | Human-like semantic perspective across the ongoing conversation |
| **Comprehension type** | Acoustic-statistical token likelihood | Deep semantic reasoning over topic, entities, domain terminology, and discourse logic |
| **Failure mode on homophones** | Emits whichever words best match local acoustic priors (`"land sun live"`) | Recognizes that `"land sun live"` is acoustically identical to `"Lanson Live"`—and only the latter makes semantic sense in an API integration discussion |

The gap in semantic comprehension between an acoustic model's internal decoder and a dedicated reasoning LLM is orders of magnitude wide. An ASR model hears sound; a reasoning model understands what the conversation is actually about.

## Full reasoning power, strictly constrained to speaker-faithful recovery

A critical principle of Lanson Live's design is how that separate reasoning model is governed:

**We use the reasoning model's deep language comprehension, but constrain its task strictly to faithfully recovering the speaker's original words.**

A language reasoning model does not lose its reasoning capability just because it is not executing intent analysis, task planning, or tool calling. Instead, by stripping away open-ended generation tasks, Lanson Live channels the model's entire reasoning capacity into a single surgical question:

> *"Given the conversation history, the topic under discussion, and the phonetic shape of what was just recognized, did the ASR candidate mishear any words—and if so, what did the speaker actually say?"*

## Controlling the double-edged sword of AI in real-time speech

Introducing an LLM into real-time transcription is a double-edged sword. Without strict architectural constraints, a general-purpose LLM often makes live captions **worse**:

- **The Paraphrasing Trap**: Unconstrained LLMs act like editors—rewriting grammar, smoothing spoken cadence, or summarizing what the speaker said instead of transcribing it.
- **The Short-Clip Hallucination Trap**: In real-time streaming, segments are short (`2–10s`). An unconstrained LLM given a brief fragment often fabricates words to force the fragment into a textbook sentence.
- **The Over-Correction Trap**: Without phonetic plausibility constraints, a text-only LLM replaces unusual but accurately recognized words with generic clichés.

Lanson Live enforces four pipeline guardrails so the reasoning model improves accuracy without ever corrupting speaker intent:

1. **Phonetic plausibility constraint**: Any correction must match the acoustic footprint of what was spoken (`"land sun live"` → `"Lanson Live"`), preventing free-form word substitution.
2. **Zero paraphrasing mandate**: Sentence structure, phrasing, and speaker voice are preserved verbatim.
3. **Disciplined non-intervention**:
   - When the ASR candidate already matches the speaker and fits the semantic context, **leaving it untouched is the only correct result**.
   - Ultra-short utterances (fewer than 3 CJK characters or 3 Latin words) bypass modification so the reasoning model never hallucinates on thin evidence—while still being appended to session context for subsequent turns.
4. **Deterministic fallback**: Raw ASR output is always preserved in `raw_text`. If refinement times out or fails, the pipeline deterministically delivers the raw recognition output.
