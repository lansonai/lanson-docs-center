Conversation meaning rarely fits inside a single sentence. A name introduced earlier, a product under discussion, or a reference from previous turns can change how the current utterance should be understood.

Lanson Live carries relevant context forward so that live reasoning is not limited to isolated audio fragments. This helps with recurring names, technical terminology, and references whose meaning becomes clear over a conversation.

::

## What is cross-utterance context

Conversation meaning rarely fits inside a single sentence. A short follow-up like *"Check the LiveFinal latency metrics"* is hard to resolve from sound alone—`"LiveFinal"` can be acoustically close to other phrases. With prior turns in view, the meaning is clear: the conversation is already about deploying LiveFinal.
