Use this guide to connect to Realtime and receive your first completed transcript. The server-side example uses an API key. For a browser, first issue a short-lived session token from your backend; never expose the API key in frontend code. The example shows where captured PCM audio is sent; for microphone capture and encoding, follow [Audio Input](/docs/realtime/audio-input).

::callout{icon="i-lucide-info" color="primary"}
**Passing `language` is recommended when you know it**, because it improves accuracy. If you do not know the language, omit it or send `language: "auto"` and the service auto-detects it. You can also call [`POST /v1/audio/language-detection`](/docs/api-reference/language-detection) first and pass the detected code. Send `"auto"` again mid-session to re-detect after a language change; an explicit code always wins.
::

## Node.js / TypeScript

```typescript
import WebSocket from "ws";

const BASE = "wss://audio.lansonai.com";
const SK = "sk-...";

const ws = new WebSocket(`${BASE}/v1/audio/transcriptions/stream`, {
  headers: { Authorization: `Bearer ${SK}` },
});

ws.on("open", () => {
  // Recommended: set the audio language before sending audio
  ws.send(JSON.stringify({ type: "session.update", language: "en" }));

  // Send PCM16LE base64 audio frames (100ms recommended)
  ws.send(JSON.stringify({
    type: "input_audio_buffer.append",
    audio: "<base64 PCM16LE>",
  }));

  // Continue sending real audio frames, including natural pauses.
  // Server-side VAD ends each utterance; do not rely on manual flush.
});

ws.on("message", (data) => {
  const event = JSON.parse(data.toString());
  switch (event.type) {
    case "session.created":
      console.log("Session:", event.session_id, "Plan:", event.plan);
      break;
    case "conversation.item.input_audio_transcription.completed":
      console.log(`[${event.utterance_index}] ${event.text}`);
      break;
    case "error":
      console.error("Error:", event.code, event.message);
      break;
  }
});

ws.on("close", (code) => console.log(`Closed: ${code}`));
```

## Browser JavaScript

Browser connections require a session token obtained from your backend:

```javascript
// 1. Get session token from your backend
const { token } = await fetch("/your-backend/session-token", {
  method: "POST",
}).then(r => r.json());

// 2. Open WebSocket
const ws = new WebSocket(
  `wss://audio.lansonai.com/v1/audio/transcriptions/stream?access_token=${token}`
);

ws.onopen = () => {
  // Recommended: set the audio language before sending audio
  ws.send(JSON.stringify({ type: "session.update", language: "en" }));

  // 3. Capture microphone audio at 16kHz mono
  const ctx = new AudioContext({ sampleRate: 16000 });
  navigator.mediaDevices.getUserMedia({ audio: true }).then((stream) => {
    const source = ctx.createMediaStreamSource(stream);
    // Use AudioWorklet to convert to PCM16LE, then send base64 JSON frames:

    //   audio: base64Pcm16le,

};

ws.onmessage = (event) => {

```

## Python

```python
import json, websocket

ws = websocket.create_connection(
    "wss://audio.lansonai.com/v1/audio/transcriptions/stream",
    header=["Authorization: Bearer sk-..."]
)

print(json.loads(ws.recv()))  # session.created

# Recommended: set the audio language before sending audio
ws.send(json.dumps({"type": "session.update", "language": "en"}))

ws.send(json.dumps({
    "type": "input_audio_buffer.append",
    "audio": "<base64 PCM16LE>"
}))
# Continue sending real audio frames, including natural pauses, for server VAD.

while True:
    event = json.loads(ws.recv())
    if event["type"] == "conversation.item.input_audio_transcription.completed":
        print(f"[{event['utterance_index']}] {event['text']}")
    elif event["type"] == "error":
        print(f"Error: {event['code']}: {event['message']}")
        break
```

## Know when it worked

When the server sends `conversation.item.input_audio_transcription.completed`, read the `text` field. That is the completed transcript for the utterance. The example logs it to the console.
